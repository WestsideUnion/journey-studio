# 16 — About + Art Direction

## About page

The About page should explain the overlap rather than forcing Maheen into one title.

Suggested framing:

**Artist. Photographer. Creative storyteller. Community builder.**

Journey Studio brings those worlds together.

### About layout

1. Full-width portrait / environmental image
2. Large positioning statement
3. Short biography
4. Disciplines
5. Selected creative milestones
6. Exhibitions / curation / talks
7. Community work
8. Current focus
9. Start a Project CTA

Use a timeline only if it remains visually clean.

## Credentials

Create editable data for:
- exhibitions
- curation
- talks / panels
- creator collaborations
- community roles
- notable art releases

Only publish verified entries.

## Art page

This should feel more like a gallery than a store.

### Sections

1. Artist statement
2. Featured artwork
3. Selected series
4. Photography as art
5. Digital / 3D work
6. Exhibitions
7. Curation
8. Prints
9. Commission / collector inquiry

### Print presentation

For each print:
- title
- year
- medium
- dimensions / available sizes
- edition information
- optional short story
- availability
- inquiry CTA

If no checkout exists, use:
`INQUIRE ABOUT THIS WORK`
