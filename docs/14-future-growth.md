1. upload her own reference image
2. analyze composition, lighting, palette, and mood
3. generate visually related concepts
4. create pitch mockups
5. create campaign treatments
6. create pre-production references

This is an internal creative tool, not necessarily a public website feature.

Generated imagery should expand the visual world rather than impersonate finished documentary photography.
