# Journey Studio Website — Antigravity Build Pack

This repository handoff is a Markdown-first specification for building the Journey Studio website in Google Antigravity.

## Goal

Build a cinematic, editorial, high-contrast creative studio website inspired by the supplied Journey Studio mockup.

Journey Studio should feel like a hybrid of:

- creative studio
- artist portfolio
- photography / film portfolio
- brand-content studio
- community and culture platform

The site should make it immediately clear that Maheen can be hired for freelance projects and brand collaborations while still preserving an artist-first identity.

## Recommended stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- Framer Motion for restrained animation
- Vercel for hosting
- GitHub for source control
- Resend for project-inquiry email delivery
- Supabase only when persistence, lead tracking, CMS-like content, or authentication is needed

## Start here in Antigravity

1. Open this folder as the workspace.
2. Tell Antigravity: `Read AGENTS.md and all docs before implementing. Build the site from the master brief.`
3. Use `docs/00-master-build-brief.md` as the canonical product brief.
4. Use `assets/references/journey-studio-blue-mockup.png` as the primary visual reference.
5. Do not redesign the visual direction unless explicitly asked.
6. Build the homepage first.
7. Verify desktop and mobile.
8. Add the inquiry flow.
9. Add case-study/project routes.
10. Deploy to Vercel only after the acceptance checklist passes.

## Source of truth

If instructions conflict, follow this priority:

1. `AGENTS.md`
2. `docs/00-master-build-brief.md`
3. `docs/01-design-system.md`
4. `docs/02-site-architecture.md`
5. page-specific docs
6. implementation details generated by the coding agent

## Important

The site must not look like a generic SaaS or template agency website.

The visual identity should feel cinematic, human, artistic, slightly experimental, and editorial.
